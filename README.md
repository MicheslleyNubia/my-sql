# MySQL Studies

## Objetivo

Repositório desenvolvido para prática de comandos e consultas SQL utilizando MySQL.

## Conceitos praticados

- SELECT
- DISTINCT
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- GROUP BY
- HAVING
- UNION
- CASE
- SUBQUERIES
- VIEWS

## Aprendizados

Durante este projeto pratiquei consultas SQL voltadas para manipulação, filtragem, agregação e relacionamento de dados.
